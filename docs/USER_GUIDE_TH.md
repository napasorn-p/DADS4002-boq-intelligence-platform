### ขั้นที่ 3: สร้างฐานข้อมูลใน MySQL

1. เปิด MySQL Workbench แล้วเชื่อมต่อ `localhost:3306`
2. **ถ้าเคยสร้างฐานข้อมูลเวอร์ชันเก่าไว้** ให้รันคำสั่งนี้ก่อน (ข้อมูลเดิมจะหายทั้งหมด):
   ```sql
   DROP DATABASE IF EXISTS boq_intelligence;
   ```
3. File → Open SQL Script → เลือก `schema.sql` → กดปุ่มสายฟ้า (Execute)
4. ตรวจผล:
   ```sql
   USE boq_intelligence;
   SHOW TABLES;
   SELECT source_name, source_kind FROM price_sources;
   ```
   ต้องเห็น 8 ตาราง และแหล่งราคา 6 แห่ง (MOC Open Data CSI + ร้านค้า 5 ร้าน)

```text

```

สถานะการจับคู่ที่จะเห็น:

| สถานะ | ความหมาย |
|---|---|
| `AUTO_MATCHED` | รหัส/ชื่อ/หน่วยตรงทุกอย่าง ระบบจับคู่ให้เอง |
| `NEEDS_REVIEW` | มีตัวเลือกที่ใกล้เคียง ต้องให้คนยืนยัน |
| `UNMATCHED` | ไม่มีวัสดุที่หน่วย/สเปกเข้ากันได้ |
| `USER_CONFIRMED` | ผู้ใช้ยืนยันเองแล้ว |

> ระบบไม่แปลงหน่วยให้ เช่น เหล็กกรอกเป็น "เส้น" จะเทียบกับราคาที่เป็น "ตัน" ไม่ได้

### ขั้นที่ 11: ดู / แก้ไข / ลบ (เมนู 6) — ส่วน Read, Update, Delete

```text
เลือกเมนู: 6
Project ID: 1
1: คอนกรีตผสมเสร็จ 300 ksc | 12.0000 ลบ.ม. | BOQ ฿3500 | AUTO_MATCHED | คอนกรีตผสมเสร็จ...
แก้รายการ (U), ลบรายการ (D), หรือ Enter กลับ:
```

- **U (แก้ไข):** ใส่ Item ID → จำนวนใหม่ → ราคาใหม่ (เว้นว่าง = คงค่าเดิม, พิมพ์ `-` = ล้างราคา)
- **D (ลบ):** ใส่ Item ID แล้วพิมพ์ `DELETE <id>` ให้ตรง เช่น `DELETE 3` เพื่อยืนยัน
  การลบเป็น soft delete คือแถวยังอยู่ในฐานข้อมูลเพื่อเก็บหลักฐาน แต่ไม่ถูกนับในการวิเคราะห์

### ขั้นที่ 12: ตรวจราคาที่ถูกพัก (เมนู 8)

ราคาที่สูงหรือต่ำผิดปกติเมื่อเทียบกับประวัติของแหล่งเดียวกัน (วิธี IQR) จะถูกพักไว้ ยังไม่นำไปคำนวณ
เลือก Observation ID แล้วพิมพ์ `valid` (ใช้ได้) หรือ `rejected` (ไม่ใช้)

### ขั้นที่ 13: Dashboard + Insight + Action Plan (เมนู 7)

ใส่ Project ID แล้วระบบจะแสดงตามลำดับ:

1. **สรุปโครงการ:** จำนวนรายการ จำนวนที่จับคู่แล้ว ต้นทุนรวมตาม BOQ
2. **เทียบราคา BOQ กับราคากลาง สนค.** (บวก VAT แล้ว): ส่วนต่างเป็นบาทและเป็น %
3. **วัสดุ Top 3 ตามต้นทุน:** รายการที่กินงบมากที่สุด (จำนวน × ราคา)
4. **ร้าน Top 3 ต่อวัสดุ:** ร้านที่ราคาต่ำสุด 3 อันดับของแต่ละวัสดุ
5. **ร้าน Top 3 ทั้งตะกร้า:** จัดอันดับเฉพาะร้านที่มีราคาครบทุกรายการ
6. **โอกาสประหยัดโดยประมาณ:** ต้นทุน BOQ − ยอดตะกร้าร้านที่ถูกที่สุด
7. **Action Plan:** เรียงจากความสำคัญสูงไปต่ำ

| Keyword | เกิดเมื่อ | สิ่งที่ควรทำ |
|---|---|---|
| `VERIFY_SPEC` | ยังมีรายการไม่ได้จับคู่ | ตรวจสเปก/หน่วย แล้วยืนยันการจับคู่ |
| `SET_LOCATION` | โครงการไม่มีรหัสจังหวัด | ใส่รหัสพื้นที่ (`10`) |
| `REQUEST_QUOTES` | รายการต้นทุนสูงยังไม่มีราคาร้าน | ขอใบเสนอราคาอย่างน้อย 3 ร้าน |
| `COMPLETE_PRICE_COVERAGE` | ไม่มีร้านใดมีราคาครบ | เติมราคาร้านให้ครบก่อนจัดอันดับ |
| `ADD_BUDGET_BASELINE` | BOQ ยังมีราคาไม่ครบ | เติมราคาต่อหน่วยใน BOQ |
| `NEGOTIATE_PRICE` | BOQ แพงกว่าราคากลางเกิน 10% | ใช้ราคากลางเป็นหลักฐานต่อรอง |
| `CHECK_UNDERBUDGET` | BOQ ถูกกว่าราคากลางเกิน 10% | ตรวจว่าราคาเก่าหรือสเปกต่ำไปหรือไม่ |
| `LOAD_OFFICIAL_PRICE` | ไม่มีราคากลางที่ตรง | นำเข้า Dataset 2 / ตรวจการจับคู่ |
| `MONITOR_PRICE` | ราคากลางเดือนล่าสุดสูงขึ้น | ตรวจราคาซ้ำก่อนสั่งซื้อ |
| `REVIEW_TOP_COST` | มีรายการต้นทุนสูง | ทบทวนปริมาณ/สเปก 3 รายการแรก |
| `VALIDATE_SAVING` | ตะกร้าร้านถูกกว่า BOQ | ยืนยันสต็อก ค่าส่ง VAT ก่อนนับเป็นเงินประหยัด |
| `REVIEW_BUDGET` | ตะกร้าร้านแพงกว่า BOQ | ปรับงบหรือขอราคาใหม่ |
| `KEEP_MONITORING` | ไม่มีเรื่องต้องแจ้ง | อัปเดตราคาเป็นระยะ |
