# DADS4002-boq-intelligence-platform

## 1. ชื่อและเป้าหมายของโปรเจค

**BOQ Intelligence Platform** — ระบบวิเคราะห์ราคาวัสดุก่อสร้างและประมาณราคาค่าวัสดุ

โปรเจครายวิชา DADS 4002 Programming Project ภาคเรียนที่ 1/2569 (กลุ่ม 3 คน, สาธิตสด)
พัฒนาด้วย Python + MySQL ใช้งานผ่านเมนูบน command line (CLI) ด้วยคำสั่ง `python main.py` ไม่มี GUI

เป้าหมาย:
- รวบรวมราคาวัสดุก่อสร้างรายเดือนจากข้อมูลจริงของ สนค. เก็บลงฐานข้อมูล
- ค้นหาและเปรียบเทียบราคาวัสดุ
- ประมาณราคาค่าวัสดุจากรายการที่ผู้ใช้เลือก
- วิเคราะห์แนวโน้มราคาเพื่อหา insight และเสนอ action plan

> ใช้ข้อมูลจริงเท่านั้น ไม่มีการสร้างข้อมูลปลอมหรือข้อมูลสังเคราะห์

## 2. ชุดข้อมูล

- **แหล่งข้อมูล:** สำนักงานนโยบายและยุทธศาสตร์การค้า (สนค.) ผ่าน API `index-api.tpso.go.th`
- **ช่วงเวลา:** ม.ค. 2563 – ต.ค. 2569 (รายเดือน)
- **พื้นที่:** ส่วนกลาง
- **ลักษณะราคา:** ราคาเงินสด ไม่รวมภาษีมูลค่าเพิ่ม (VAT) และไม่รวมค่าขนส่ง

**ข้อควรระวัง**
- รายการวัสดุเปลี่ยนไปตามเวลา: บางรายการถูกเพิ่มหรือยกเลิกในช่วงที่ต่างกัน จึงไม่ได้มีข้อมูลครบทุกเดือน
- บางหมวดไม่มีราคาหลังต้นปี 2569
- หมวดท่อมีสัดส่วนจำนวนรายการสูงกว่าหมวดอื่น ควรระวังเมื่อสรุปผลรวมหรือค่าเฉลี่ยข้ามหมวด

## 3. วิธีติดตั้งทีละขั้น

**ขั้นที่ 1: ติดตั้งโปรแกรมพื้นฐาน**
- ติดตั้ง [Git](https://git-scm.com/downloads)
- ติดตั้ง [Python](https://www.python.org/downloads/) เวอร์ชัน 3.10 ขึ้นไป (บน Windows ให้ติ๊ก "Add Python to PATH" ตอนติดตั้ง)

**ขั้นที่ 2: ดาวน์โหลดโปรเจค (clone)**
เปิด Terminal (Mac) หรือ Command Prompt / PowerShell (Windows) แล้วพิมพ์:
```bash
git clone https://github.com/napasorn-p/DADS4002-boq-intelligence-platform.git
```
```bash
cd DADS4002-boq-intelligence-platform
```

**ขั้นที่ 3: สร้าง virtual environment และติดตั้งไลบรารี**
```bash
python -m venv .venv
```
เปิดใช้งาน (Mac/Linux):
```bash
source .venv/bin/activate
```
เปิดใช้งาน (Windows):
```bash
.venv\Scripts\activate
```
ติดตั้งไลบรารี:
```bash
pip install -r requirements.txt
```

**ขั้นที่ 4: เตรียมฐานข้อมูล** เลือกอย่างใดอย่างหนึ่ง
- **MySQL บนเครื่อง:** ติดตั้ง [MySQL Community Server](https://dev.mysql.com/downloads/) แล้วสร้างฐานข้อมูลเปล่า 1 อัน
- **TiDB Cloud (ฟรี, ใช้ร่วมกันได้ทั้งกลุ่ม):** สมัครที่ [tidbcloud.com](https://tidbcloud.com) สร้าง cluster แบบ Serverless แล้วกด Connect เพื่อดู host, port, user, password และดาวน์โหลดไฟล์ CA certificate

**ขั้นที่ 5: สร้างไฟล์ .env**
คัดลอกไฟล์ `.env.example` แล้วตั้งชื่อใหม่ว่า `.env` จากนั้นเปิดไฟล์และกรอกข้อมูลการเชื่อมต่อฐานข้อมูล
(ถ้าใช้ TiDB Cloud ให้ใส่ path ของไฟล์ CA ที่ `DB_SSL_CA` ถ้าใช้ MySQL บนเครื่องเว้นว่างได้)
> ห้าม commit ไฟล์ `.env` เด็ดขาด (ไฟล์นี้ถูกใส่ไว้ใน `.gitignore` แล้ว)

**ขั้นที่ 6: ดึงข้อมูลจาก สนค.**
```bash
python scripts/pull_tpso.py
```
ไฟล์ข้อมูลดิบจะถูกเก็บในโฟลเดอร์ `data_raw/` (ไม่ถูก commit)

**ขั้นที่ 7: สร้างตารางในฐานข้อมูล**
รันไฟล์ `schema.sql` ในฐานข้อมูล เช่น ผ่าน MySQL Workbench / หน้า SQL Editor ของ TiDB Cloud หรือคำสั่ง:
```bash
mysql -h <DB_HOST> -P <DB_PORT> -u <DB_USER> -p <DB_NAME> < schema.sql
```

**ขั้นที่ 8: นำเข้าข้อมูล**
```bash
python import_data.py
```

**ขั้นที่ 9: เปิดโปรแกรม**
```bash
python main.py
```

## 4. โครงสร้างโฟลเดอร์

```
.
├── main.py            # ตัวควบคุมเมนูหลัก เรียกใช้โมดูลอื่นทั้งหมด
├── db.py              # ฟังก์ชันเชื่อมต่อฐานข้อมูล (อ่านค่าจาก .env)
├── logger.py          # ตั้งค่าการบันทึก log ลงโฟลเดอร์ logs/
├── import_data.py     # นำข้อมูลจาก data_raw/ เข้าฐานข้อมูล
├── schema.sql         # คำสั่งสร้างตาราง
├── requirements.txt   # รายชื่อไลบรารี Python ที่ต้องติดตั้ง
├── .env.example       # ตัวอย่างไฟล์ตั้งค่าฐานข้อมูล (ไม่มีค่าจริง)
├── menus/
│   ├── search.py      # เมนูค้นหาวัสดุและราคา
│   ├── basket.py      # เมนูเลือกรายการวัสดุและประมาณราคารวม
│   └── exporter.py    # เมนูส่งออกผลลัพธ์เป็นไฟล์ไปที่ exports/
├── analytics/
│   └── __init__.py    # ทะเบียนรายงานวิเคราะห์ (REPORTS) ให้ main.py เรียกใช้
├── scripts/           # สคริปต์ดึงข้อมูล เช่น pull_tpso.py
├── docs/              # ER diagram และบันทึกต่าง ๆ
└── tests/             # ไฟล์ทดสอบ
```

โฟลเดอร์ที่ระบบสร้างเองและไม่ถูก commit: `data_raw/`, `logs/`, `exports/`, `.venv/`
